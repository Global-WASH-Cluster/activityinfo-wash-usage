Data limitations

  • The read uses a token VIEW-filtered to WASH, so nothing here covers other clusters.
  • Entry dates are ActivityInfo last-edit timestamps. A re-edited row moves forward in time.
  • Partner monitoring (form 5.1A) and cluster monitoring (form 6.1A) are separate streams and must not be added together.
  • Where every WASH cluster target in a module has the same value, the targets are treated as placeholders.

Method

  • A scheduled job reads every HPC Country Module through the ActivityInfo API once a day and publishes an aggregated snapshot. The page itself never contacts ActivityInfo.
  • Active: 5+ reporting orgs, 2+ periods, 100+ rows and edits in the last 60 days. Established: Active plus 10+ orgs, half of targeted indicators reported, and 25%+ of target-level admin units reached where targets have geography.
  • Snapshot data: latest.json.
